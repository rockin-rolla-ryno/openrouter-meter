● OPENROUTER METER

Install the meter software

For the Waveshare ESP32-C6-Touch-AMOLED-2.16. Use Chrome or Edge on a computer.

1. Put the display into install mode
  1. Unplug the USB cable from the display.
  2. Press and hold the BOOT button on its side.
  3. While holding it, plug the USB cable back in.
  4. Keep holding for 3 seconds, then let go. The screen stays black — that's right.
2. Install

Click the button, choose the port called USB JTAG/serial debug unit, then Install.

This browser can't install firmware. Please open this page in Chrome or Edge on a computer. Please open this page over https.
3. Restart the display

When it says Installation complete: hold PWR for 8 seconds until the screen is off, then press PWR once. You'll see “Ready to pair”. Next, install the PC app — see the setup guide.
